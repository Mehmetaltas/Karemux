# KAREMUX UI V2 — Mimari Planı

Bu paket KAREMUX'un mevcut eğitim özelliklerini silmeden, menü + eğitim akışı + ortak görsel sistemin
tek bir mimaride toplanması için hazırlanmıştır.

## Bilgi mimarisi

- Ana Sayfa
- Çalış
  - Dersler
  - Bugün
  - Zayıf Konular
- Sınavlar
  - Deneme
  - Yazılı
  - Türkiye Geneli
  - İOKBS
  - Seviye Tespit
  - Sonuçlar
- Hedef & Plan
  - Hedef Okulum
  - Haftalık Plan
  - Tatil Programı
  - LGS Puan Hesaplayıcı
- Çalışma Araçları
  - Paragraf Stüdyosu
  - Formül/Kural Kartları
  - Kelime Kartları
  - Soru Çöz
  - Sınav Kaygısı Desteği
- Gelişimim
  - Karne
  - Koç Paneli
  - Zayıf Konu Haritası
  - Başarılarım
  - Seviye Tamamlama
- Bağlantılar
  - Veli
  - Öğretmen
  - Kurum
- Premium
- Ayarlar

## Eğitim döngüsü

Ders → Ünite/Tema → Konu → Alt Konu → Anlatım → Örnek → Pratik → Test
→ Sonuç → Zayıf Konu → Tekrar → İlerleme

## Uygulama ilkesi

Bu paket mevcut API, veritabanı ve çalışan sayfaları otomatik olarak silmez.
Gerçek repo üzerinde entegrasyon yapılmadan mevcut route dosyaları değiştirilmemelidir.
